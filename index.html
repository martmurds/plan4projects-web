Frequently asked questions

Is Plan4Projects free?

Yes — Plan4Projects is completely free. The full Gantt and critical-path scheduling engine, resource management, baselines and all seven views are included, with no subscription and nothing locked behind a paywall. There is an optional tip jar if it saves you time.

Can I open Microsoft Project (.mpp) files on a Mac?

Yes. Plan4Projects reads .mpp files (Microsoft Project 98 through 2019 and later) plus around 20 other formats, and exports Microsoft Project XML that opens natively in Project. It is one of the few free, native Mac apps that can open .mpp files.

Is Plan4Projects a good alternative to Microsoft Project for Mac?

Microsoft does not make a Mac version of Project, so Plan4Projects gives Mac users a native, free way to plan: a complete critical-path (CPM) engine with four dependency types, seven constraint types, resource leveling, multiple baselines and earned-value tracking — and it opens and exports Microsoft Project files.

Does it work offline?

Yes. Plan4Projects runs entirely on your Mac with no account and no server, so you can plan with no internet connection. The optional AI assistant is the only feature that goes online, and only when you choose to use it.

Does it run on Apple Silicon (M1, M2, M3, M4)?

Yes. It is a universal app that runs natively on both Apple Silicon and Intel Macs, on macOS 10.15 (Catalina) and later, and it is signed and notarized by Apple.

Can I make a Gantt chart on a Mac with it?

Yes — the Gantt chart is the heart of the app. Add tasks, set durations and dependencies, and Plan4Projects draws a live Gantt chart with the critical path highlighted, baseline bars and dependency arrows. Timeline, Network (PERT), Calendar and Dashboard views are built in too.

Do I need to install Java or anything else?

No. Plan4Projects bundles its own runtime, so there is nothing else to install — just download it, open it, and start planning.

Is my project data private?

Yes. Your projects are stored locally on your Mac and are never sent to a Plan4Projects server. If you use the AI assistant you bring your own Anthropic API key, which is stored in the macOS Keychain.

Free to use.

Plan4Projects is free and built by one developer. If it saves you time, you’re welcome to leave a tip — never required.
